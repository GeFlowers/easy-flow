# 前端功能模块

按业务能力划分目录：`threads` 管理对话，`messages` 处理消息，`memory` 管理长期记忆，
`skills` 管理技能，`channels` 管理外部消息连接，其他目录同样以具体能力命名。

功能的数据类型、请求函数和业务钩子放在同一模块，页面路由放在 `../app`，界面组件放在
`../components`。`api`、`config`、`i18n` 等是这些功能共用的服务模块，不是独立页面。

只有不绑定业务功能的基础函数才放入 `../lib`；跨功能复用的通用界面钩子放入 `../hooks`，
共享类型声明放入 `../types`。不要将业务请求重新堆进通用工具目录。
