# 快速上手

当前学习版在 Windows 本机运行前端、后端和 Nginx，只有 PostgreSQL 使用容器，Redis 在本机单独运行。

1. 安装 Python 3.12 或以上、uv、Node.js 22 或以上、Corepack、Nginx、Docker 和 Make。
2. 复制根目录及前端目录的环境示例文件，准备 `config/config.yaml` 和 `config/extensions_config.json`，填写模型凭据及数据库连接。
3. 在根目录环境文件设置 `NGINX_HOME`，将仓库的 `deploy/nginx/nginx.conf` 复制到安装目录的 `conf/nginx.conf`。
4. 启动本机 Redis，安装依赖并构建前端：

```bash
cd backend
uv sync --frozen --no-dev --extra postgres --extra redis --extra pymupdf
cd ../frontend
corepack pnpm install --frozen-lockfile
corepack pnpm build
cd ..
```

全新部署需要先创建 `deer-flow-dev_postgres-data` 卷；迁移已有数据库时应先检查原卷，不要以空卷替代。

```bash
docker volume create deer-flow-dev_postgres-data
bash scripts/start.sh
```

打开 [http://localhost:2026](http://localhost:2026)，没有管理员时先完成初始化。

日常使用 `bash scripts/stop.sh` 停止前后端及数据库容器，数据库卷和 Nginx 会保留。

[部署指南](/docs/application/deployment-guide)说明自启动和数据位置，[运维与排障](/docs/application/operations-and-troubleshooting)说明日志及常见故障。
