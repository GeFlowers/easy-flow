# 快速上手

<Callout type="info" emoji="⚡">
  大约 10 分钟即可通过 Docker 运行 DeerFlow。你需要 Docker Compose 和至少一个 LLM API Key。
</Callout>

本指南介绍如何使用项目的 Docker Compose 配置启动 DeerFlow。Gateway、前端、PostgreSQL 和 nginx 都在容器中运行，并通过同一个地址访问。

## 前置条件

检查 Docker 是否可用：

```bash
make docker-init
```

必需工具：

| 工具   | 要求 |
| ------ | ---- |
| Docker | Docker Engine/Desktop，且支持 Compose |

## 步骤

<Steps>

### 克隆仓库

```bash
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow
```

### 配置模型

首次运行 `make docker-start` 时，如果 `config.yaml` 不存在，会从示例文件创建。然后在 `models:` 下至少添加一个模型：

```yaml
models:
  - name: gpt-4o
    use: langchain_openai:ChatOpenAI
    model: gpt-4o
    api_key: $OPENAI_API_KEY
    request_timeout: 600.0
    max_retries: 2
    supports_vision: true
```

将对应的 API Key 写入项目根目录的 `.env` 文件：

```bash
OPENAI_API_KEY=sk-...
```

查看[配置](/docs/application/configuration)页面了解其他模型提供商的示例。

### 启动 DeerFlow

```bash
make docker-start
```

这会启动：

- Gateway API、前端、PostgreSQL 和 nginx 容器

在浏览器中打开 [http://localhost:2026](http://localhost:2026)。

### 停止所有服务

```bash
make docker-stop
```

</Steps>

## `make docker-start` 做了什么

- 构建前后端镜像，并在后台启动应用服务。
- nginx 通过端口 `2026` 代理所有流量，所以你只需要一个 URL。

日志文件：

| 服务    | 命令 |
| ------- | ---- |
| 全部服务 | `make docker-logs` |
| Gateway | `make docker-logs-gateway` |
| 前端    | `make docker-logs-frontend` |

<Callout type="tip">
  如果有问题，先检查 Gateway 容器日志。大多数启动错误（缺失 API Key、配置解析失败）会出现在其中。
</Callout>
