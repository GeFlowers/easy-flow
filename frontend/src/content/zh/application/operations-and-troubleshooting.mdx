# 运维与排障

## 日志与状态

前后端日志直接位于项目根目录的 `logs`，数据库日志可使用容器管理工具查看，Nginx 日志位于安装目录的 `logs`。

```bash
Get-Content logs/gateway.err.log -Tail 50
Get-Content logs/frontend.err.log -Tail 50
```

查看或分享日志前先检查是否包含凭据，不要直接打印整个环境文件。

## 常见问题

- 代理返回上游不可用：确认已执行 `bash scripts/start.sh`，查看前后端日志；代理自启不会自动启动前后端。
- 数据库连接失败：检查数据库容器健康、原数据卷是否存在，以及环境文件中的地址和密码。迁移时不要创建空卷冒充原数据。
- Redis 连接失败：确认本机服务正在运行，连接地址和认证配置一致。
- 端口被占用：启动脚本会拒绝继续；先确认进程归属，不要批量结束同名进程。
- 模型请求失败：检查模型配置、密钥是否已配置和网络是否可达，不要将真实密钥贴到日志或文档。
- 构建失败：进入前端目录运行 `corepack pnpm build`；安装依赖请参照快速上手。
- 工具或文件路径失败：检查本机目录是否存在、后端账户权限，以及命令执行是否允许。本机沙箱不再使用应用容器中的目录。

## 更新与重启

```bash
bash scripts/stop.sh
cd frontend && corepack pnpm build && cd ..
bash scripts/start.sh
```

依赖变化时先重新安装依赖。修改环境文件后要重启前后端；只重载代理不会刷新后端环境变量。

## 备份

分别备份 PostgreSQL 和完整的 `backend/.deer-flow`，以及私有配置。后端停止时会正常关闭运行时并刷新记忆队列；不要直接强制结束进程代替日常停止。
