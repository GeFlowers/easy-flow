# 部署你的 DeerFlow

本学习版只维护 Windows 本机应用部署：前端、后端和 Nginx 在本机运行，PostgreSQL 在容器中运行，Redis 在本机单独维护。

按照[快速上手](/docs/application/quick-start)准备私有配置、依赖和代理目录，再执行：

```bash
cd backend && uv sync --frozen --no-dev --extra postgres --extra redis --extra pymupdf && cd ../frontend
corepack pnpm install && corepack pnpm build && cd ..
bash scripts/start.sh
```

首次创建数据库卷与迁移原数据库是不同操作，详见[部署指南](/docs/application/deployment-guide)。浏览器访问 [http://localhost:2026](http://localhost:2026)。

本机默认配置不面向公网。公开部署需重新考虑网络隔离、传输加密、登录安全、备份和本机命令执行风险，不能直接将这套学习配置视为生产部署。
