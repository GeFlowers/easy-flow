# Deploy Your Own DeerFlow

This learning edition runs the frontend, backend and Nginx on Windows, with PostgreSQL in Docker and Redis maintained locally.

Follow [Quick Start](/docs/application/quick-start) to prepare private configuration, dependencies and Nginx, then run:

```bash
cd backend && uv sync --frozen --no-dev --extra postgres --extra redis --extra pymupdf && cd ../frontend
corepack pnpm install && corepack pnpm build && cd ..
bash scripts/start.sh
```

Creating a database for the first time differs from migrating an existing one. See [Deployment Guide](/docs/application/deployment-guide), then open [http://localhost:2026](http://localhost:2026).

The defaults are local-only. Public deployment needs a separate review of network isolation, encrypted transport, authentication, backups and host command execution. This learning configuration is not a production security design.
