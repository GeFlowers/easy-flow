# Quick Start

<Callout type="info" emoji="⚡">
  Start DeerFlow in Docker in about 10 minutes. You need Docker Compose and at
  least one LLM API key.
</Callout>

This guide walks you through starting DeerFlow with the project's Docker Compose configuration. Gateway, frontend, PostgreSQL, and nginx run in containers and are accessible through one URL.

## Prerequisites

Check that Docker is available:

```bash
make docker-init
```

Required:

| Tool   | Requirement |
| ------ | ----------- |
| Docker | Docker Engine/Desktop with Compose support |

## Steps

<Steps>

### Clone the repository

```bash
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow
```

### Configure a model

On first startup, `make docker-start` creates `config.yaml` from the example if needed. Add at least one model under the `models:` section:

```yaml
models:
  - name: gpt-4o
    use: langchain_openai:ChatOpenAI
    model: gpt-4o
    api_key: $OPENAI_API_KEY
    request_timeout: 600.0
    max_retries: 2
    supports_vision: true
```

Put the corresponding API key in the project-root `.env` file:

```bash
OPENAI_API_KEY=sk-...
```

See the [Application Configuration](/docs/application/configuration) page for examples with other model providers.

### Start DeerFlow

```bash
make docker-start
```

This starts:

- Gateway API, frontend, PostgreSQL, and nginx in Docker containers

Open [http://localhost:2026](http://localhost:2026) in your browser.

### Stop all services

```bash
make docker-stop
```

</Steps>

## What happens when you run `make docker-start`

- Docker builds the frontend and backend images, then starts the application services in the background.
- nginx proxies the application through port `2026`, so you only need one URL.

Log files:

| Service   | Command |
| --------- | ------- |
| All       | `make docker-logs` |
| Gateway   | `make docker-logs-gateway` |
| Frontend  | `make docker-logs-frontend` |

<Callout type="tip">
  If something is not working, check the Gateway container logs first. Most
  startup errors (missing API keys, config parsing failures) appear there.
</Callout>
