# Quick Start

This learning edition runs the frontend, backend and Nginx on Windows. Only PostgreSQL runs in Docker; Redis runs separately on the host.

1. Install Python 3.12 or later, uv, Node.js 22 or later, Corepack, Nginx, Docker and Make.
2. Copy the root and frontend environment examples, prepare `config/config.yaml` and `config/extensions_config.json`, and configure model credentials and the database connection.
3. Set `NGINX_HOME` in the root environment file. Back up the original Nginx configuration before copying `deploy/nginx/nginx.conf` to its installation's `conf/nginx.conf`.
4. Start local Redis, then install dependencies and build:

```bash
cd backend
uv sync --frozen --no-dev --extra postgres --extra redis --extra pymupdf
cd ../frontend
corepack pnpm install --frozen-lockfile
corepack pnpm build
cd ..
```

A new installation needs the `deer-flow-dev_postgres-data` volume. When migrating an existing database, verify the original volume instead of replacing it with an empty one.

```bash
docker volume create deer-flow-dev_postgres-data
bash scripts/start.sh
```

Open [http://localhost:2026](http://localhost:2026). Initialize the administrator if the database has none.

Run `bash scripts/stop.sh` to stop the frontend, backend, and database container. The database volume and Nginx remain.

See [Deployment Guide](/docs/application/deployment-guide) and [Operations and Troubleshooting](/docs/application/operations-and-troubleshooting).
